# PM — Kevin Niparko (Day 1)

## Três primitivas de PM
1. Attention List (sinal emergente vs TODOs velhos).
2. Research across customer context (Gong/Granola/Databricks/Notion/tickets).
3. Shipping via cloud agents (decompose / allocate / review / integrate).

## Staff uma virtual org por role
Chief of Staff, EM, ICs, data, product, design, recruiter — não uma caixa em branco.

## Por que muitos agentes
- Referenceability, memória escopada, paralelismo (ship enquanto research roda enquanto recruiting mantém quente).

## Demo loop
Chat → Notion/data conectado → funnel chart → bottleneck → PRD durável → instrumentação P0 nomeada + pixel-lock handoff.

## Lessons
- Agentes nomeados + memória separada.
- Aprenda no job (style guides do Slack).
- Fique quieto a menos que precise.
- Agentes all the way down (EM → IC → cloud agents).
