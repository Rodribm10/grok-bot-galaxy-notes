## Modelo central
- Bots = roles/outcomes, não chats one-off.
- Cada bot tem computador na nuvem.
- Um bot por job; volte para ele aprender.
- Maturity: Ask → Do → Delegate → Staff.
- Templates compartilháveis + rotinas + handoff bot-a-bot.
- Humanos aprovam ações externas (send, refund, publish, pay, CRM write).

## Day 3 — o que entrou
- MarOps: dream team (CoS + EA + PM + Engineer). Handoff aceitar/rejeitar/skip com CRM como source of truth e end reason. Governed agency: mensagem e write de CRM não saem sem humano.
- Post-sales: um CoS na frente; especialistas atrás; drafts only / nothing sent; rotinas de brief, call prep, promessas, ask watch; living system = correção + review semanal.
- Marketing: cadeia research → brief/positioning → site → ads → scorecard → PM. Sem publish no meio. Scope como job description.
- Showcase 72h: Thursday Arena / Cupcake (rótulos coexistiram). Loop Draft 3 → Lineup → Auto battle → Result/share. Fábrica: play test → review/approve → land main. End card sem wrap nomeado. KPIs de jogo ≠ receita.
